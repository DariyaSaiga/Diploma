\chapter{Conclusion}
\label{chap:conclusion}

This diploma project presented the development and evaluation of a multimodal emotion recognition system based on an attention bottleneck mechanism. The main goal of the work was to design a system that can process textual, acoustic, and visual information and recognise six emotion categories from the CMU-MOSEI dataset: happiness, sadness, anger, surprise, disgust, and fear. The project addressed three main challenges in multimodal emotion recognition: effective fusion of heterogeneous modalities, class imbalance, and the practical integration of a trained model into a prototype system.

The results of this work are structured in accordance with the research objectives defined in the Introduction. Each objective was addressed during the course of the study, as demonstrated in the following outcomes:

First, existing approaches to multimodal emotion recognition and attention-based fusion were studied, forming the theoretical basis of the proposed architecture.

Second, the CMU-MOSEI dataset was analyzed and precomputed multimodal features were prepared for model training.

Third, a multimodal architecture based on an attention bottleneck mechanism was designed and implemented for controlled cross-modal interaction.

Fourth, the model was trained under class imbalance conditions using weighted loss functions and regularization techniques such as modality dropout.

Fifth, the system was evaluated using macro-F1, weighted accuracy, and per-class F1 scores.

Finally, the proposed approach was compared with baseline fusion methods, demonstrating the effectiveness of bottleneck-based fusion.

The proposed architecture combines modality-specific encoders with a bottleneck attention fusion module. The text stream uses frozen BERT-base-uncased representations, where the final text features come from the averaged last four hidden layers. This strategy gives the model strong contextual language information without updating all BERT parameters during training. The audio stream uses COVAREP acoustic descriptors, while the visual stream uses OpenFace facial action unit features. The system projects all three streams into a shared hidden dimension before fusion. This step allows the model to process text, audio, and visual information in a common representation space.

The central part of the proposed model is the attention bottleneck fusion module. Instead of allowing full pairwise attention between all modality tokens, the model uses 16 learnable bottleneck tokens as a compact communication channel. These tokens collect information from text, audio, and visual streams and then redistribute the shared representation back to each modality. This design encourages selective cross-modal communication and reduces unnecessary interaction between irrelevant parts of the input sequences. The model also uses auxiliary classification heads and modality dropout to reduce dependence on a single dominant stream.

The experimental results show that the proposed bottleneck-based architecture improves multimodal emotion recognition compared with the implemented baselines. The late fusion baseline achieved an Avg.~F1 of 0.4412, while the MulT-style baseline achieved 0.4631. The proposed model achieved 0.4854 with the default threshold and 0.4942 after per-class threshold tuning. This means that bottleneck attention improved Avg.~F1 by 4.42 percentage points compared with the late fusion baseline. The result supports the main idea of the project: structured cross-modal communication can improve emotion recognition more effectively than simple concatenation or ordinary cross-modal attention.

The project also showed the importance of class imbalance handling. CMU-MOSEI contains a strong imbalance between frequent emotions such as happiness and rare emotions such as fear and surprise. For this reason, the evaluation used macro-F1 as the main metric, together with weighted accuracy and per-class F1 scores. The proposed model improved recognition of minority categories. Fear F1 increased from 0.1834 in the late fusion baseline to 0.3122 with the default threshold and 0.3451 after threshold tuning. Surprise F1 increased from 0.1902 to 0.2563 with the default threshold and to 0.3214 after tuning. These results show that weighted loss, modality dropout, and validation-based threshold selection help the model give more attention to underrepresented classes.

The ablation study helped identify which design choices contributed most to the final performance. Frozen BERT worked better than online fine-tuning because the available CMU-MOSEI training set was not large enough to safely update all BERT parameters. Averaging the last four hidden layers improved the quality of the text representation. Auxiliary losses and modality dropout also supported the final configuration. In contrast, the Semantic Enhancement Module did not improve results in this project. This suggests that architectural components from published models do not always transfer directly to another feature setting, especially when the system uses handcrafted audio and visual descriptors instead of stronger neural encoders.

The comparison with published studies showed that the proposed model achieved competitive results among systems that use compact or handcrafted acoustic and visual features. It surpassed MulT in Avg.~F1 under a comparable feature setting. At the same time, the model remained slightly below systems such as MER-SEM-MBT, which use stronger neural encoders such as VGGish and ResNet18. This difference shows that the quality of modality-specific representations still strongly affects final performance. Therefore, the main limitation of the current system is not only the fusion strategy, but also the representational capacity of COVAREP and OpenFace features.

In addition to the experimental model evaluation, the project implemented a functional prototype pipeline. The FastAPI backend can accept raw video input, extract acoustic, visual, and textual information, and return emotion probabilities through a REST API. The prototype demonstrates that the trained model can work as part of a practical software system. However, the current implementation remains a research prototype rather than a real-time production application. The main runtime cost comes from preprocessing, especially speech transcription and facial feature extraction.

The project has several limitations. First, the system relies on handcrafted audio and visual features, which limits the amount of emotional information available to the model. Second, the evaluation uses only the CMU-MOSEI dataset and does not include cross-dataset testing. Third, the dataset contains mainly English-language online videos, so the model's behaviour on other languages, accents, or cultural contexts remains unknown. Fourth, validation-based threshold tuning improves macro-F1, but the selected thresholds may not transfer perfectly to another data distribution.

Future work can address these limitations in several directions. The audio branch could use stronger pretrained speech representations such as wav2vec2, HuBERT, or VGGish. The visual branch could use a neural facial expression encoder instead of OpenFace action units. Future experiments could also test different numbers of bottleneck tokens, deeper bottleneck layers, adaptive loss functions, and stronger missing-modality handling. In the system part, future work should optimise preprocessing speed, improve video frame sampling, and test deployment on a GPU-enabled server.

Overall, this project demonstrated that attention bottleneck fusion is a useful approach for multimodal emotion recognition on CMU-MOSEI. The final system improved over both implemented baselines, achieved stronger results for minority emotions, and showed that compact bottleneck communication can support effective fusion of text, audio, and visual streams. At the same time, the study confirmed that feature quality, class imbalance, and deployment constraints remain important challenges. The developed system can therefore serve as a functional research prototype and a foundation for future work with stronger modality encoders and more efficient inference pipelines.
