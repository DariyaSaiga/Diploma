\chapter{Designations and Abbreviations}
\begin{SingleSpace}

Following designations and abbreviations are used in this work:\par\bigskip

\begin{description}[style=multiline,leftmargin=3.5cm,labelwidth=3.2cm]

  \item[AI]
        Artificial Intelligence

  \item[MER]
        Multimodal Emotion Recognition

  \item[HCI]
        Human--Computer Interaction

  \item[CMU-MOSEI]
        Carnegie Mellon University Multimodal Opinion Sentiment and Emotion Intensity Dataset

  \item[MELD]
        Multimodal EmotionLines Dataset

  \item[BERT]
        Bidirectional Encoder Representations from Transformers

  \item[CNN]
        Convolutional Neural Network

  \item[BiLSTM]
        Bidirectional Long Short-Term Memory

  \item[Transformer]
        Attention-based neural network architecture for sequence modeling

  \item[MulT]
        Multimodal Transformer

  \item[DBA]
        Domain-Separated Bottleneck Attention

  \item[XMBT]
        Extended Multimodal Bottleneck Transformer

  \item[FFN]
        Feed-Forward Network

  \item[ReLU]
        Rectified Linear Unit

  \item[BCEWithLogitsLoss]
        Binary Cross-Entropy Loss with Logits

  \item[F1-score]
        Harmonic mean of precision and recall

  \item[Macro-F1]
        Average F1-score calculated equally across all classes

  \item[Avg. WA]
        Average Weighted Accuracy

  \item[TP]
        True Positive

  \item[TN]
        True Negative

  \item[GPU]
        Graphics Processing Unit

  \item[API]
        Application Programming Interface

  \item[WS]
        WebSocket

  \item[COVAREP]
        Collaborative Voice Analysis Repository for Speech Technologies

  \item[OpenFace]
        Open-source facial behavior analysis toolkit

  \item[openSMILE]
        Open-source Speech and Music Interpretation by Large-space Extraction toolkit

  \item[AU]
        Facial Action Unit

  \item[PyTorch]
        Open-source deep learning framework

\end{description}
\end{SingleSpace}
